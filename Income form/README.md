# MyFinance Windows Forms UI

This is a C# Windows Forms App project for Visual Studio 2022, targeting .NET 8. It recreates the Income screen as a UI-only prototype using standard WinForms controls that can be edited in the Windows Forms Designer and Toolbox.

## Open in Visual Studio 2022

1. Open `PersonalFinanceUI.csproj` in Visual Studio 2022.
2. If prompted, install the **.NET desktop development** workload.
3. In Solution Explorer, right-click `IncomeForm.cs` and choose **View Designer**.
4. Press F5 to run the screen.

The summary cards and table are intentionally empty, matching the reference screenshot. Navigation highlighting and the Add Income button are presentation-only; no finance data or database is connected.
